A copied draft and an accepted original have different outcomes

A repair that merely copies the source fails when a rewrite is required. A separately reviewed original can pass if its wording already fits. A changed draft can be shown for human review when safety and meaning checks pass but issues such as clarity or register remain. A failed required check can leave the reader with no candidate text.

Consent and admission bound each submission

Typing stays local until the visitor confirms external processing. The API validates the request before inference. Edge requests share a named Durable Object. It reserves both daily allowances in one transaction and stores counts and opaque browser identifiers. Ordinary service permits 30 admissions globally and three per cooperating browser cookie jar per UTC day. Each admission allows up to 32 logical provider calls. External providers apply their own processing terms.
